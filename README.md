🚨 Burglar / Intruder / Theft Door Alarm with Buzzer

📌 Project Title

Burglar / Intruder / Theft Door Alarm with Buzzer**

📝 Project Description

The **Burglar / Intruder / Theft Door Alarm with Buzzer** is an IoT-based security system designed to detect unauthorized door opening and alert nearby individuals using a buzzer. The system uses a door sensor connected to a microcontroller to continuously monitor the door's status. When an intrusion is detected, the buzzer is activated, providing an immediate audible warning.

This project offers a simple, low-cost, and practical solution for basic security applications in homes, classrooms, laboratories, offices, and storage rooms.

## 🎯 Objectives

* To develop a low-cost IoT-based door security system.
* To detect unauthorized door opening or intrusion.
* To activate a buzzer when suspicious entry is detected.
* To provide an immediate audible alert to nearby individuals.
* To demonstrate the practical application of sensors and microcontrollers in security systems.
* To create a simple and easily implementable theft-alert solution.

## ✨ Features

* 🚪 **Door Intrusion Detection** — Detects when the protected door is opened.
* 🔊 **Buzzer Alert** — Activates an audible alarm when intrusion is detected.
* ⚡ **Real-Time Monitoring** — Continuously monitors the door's status.
* 💰 **Low-Cost Design** — Uses affordable and easily available components.
* 🔧 **Easy to Build** — Simple hardware connections and implementation.
* 🏠 **Multiple Applications** — Suitable for homes, classrooms, laboratories, offices, and storage rooms.
* 🔌 **Expandable System** — Can be enhanced with LEDs, GSM alerts, or IoT notifications.

⚙️ Working Principle

1. The door sensor continuously monitors the door's status.
2. The microcontroller reads the sensor's output.
3. When the door is opened, the system identifies a possible intrusion.
4. The buzzer is activated to produce an audible alert.
5. The alarm can be deactivated or reset according to the implemented control logic.
